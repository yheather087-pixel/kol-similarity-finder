KOL Similarity Finder

KOL Similarity Finder is an internal creator discovery and research tool used by authorized team members for YouTube creator sourcing and marketing research.

The application helps users identify relevant public YouTube creators based on content similarity, language, country, subscriber count, and average video views.

The tool is not publicly available and is used only by authorized internal users.

This application uses the YouTube Data API for public creator discovery.
