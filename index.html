Internal Creator Discovery Tool

KOL Similarity Finder

KOL Similarity Finder is an internal creator discovery and research tool used by authorized team members for creator sourcing, influencer research, and marketing campaign planning.

The application helps users identify relevant public creators based on content similarity and publicly available information such as language, country, subscriber count, and average video views.

The tool is not offered to the general public and is used only by authorized internal users.

Core Features

  • Discover creators related to a selected creator or content category.
  • Filter creators by country, language, subscriber count, and average views.
  • Review publicly available creator and video metadata.
  • Use caching and deduplication to reduce unnecessary API requests.
  • Maintain internal exclusion lists to avoid repeatedly reviewing the same creators.
Powered by YouTube Data API Services

KOL Similarity Finder uses YouTube API Services to retrieve publicly available YouTube channel, video, and search metadata for internal creator discovery and research.

The application does not upload, edit, or delete YouTube content and does not access private YouTube account information.
