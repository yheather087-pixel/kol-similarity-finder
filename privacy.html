Privacy Policy

KOL Similarity Finder is an internal creator discovery tool used by authorized team members for creator research and marketing campaign sourcing.

The application uses the YouTube Data API to access publicly available YouTube information, including public channel, video, and search metadata.

The application does not access private YouTube account information and does not upload, modify, or delete YouTube content.

Public creator data retrieved through the YouTube Data API may be stored for internal research, caching, deduplication, and creator sourcing purposes.

The application is not offered to the general public and does not sell user data or YouTube API data to third parties.
