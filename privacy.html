Privacy Policy

KOL Similarity Finder is an internal creator discovery tool used by authorized team members for creator research and marketing campaign sourcing.

Use of YouTube API Services

KOL Similarity Finder uses the YouTube Data API Services to access publicly available YouTube information, including public channel, video, and search metadata.

The application does not access private YouTube account information and does not upload, modify, or delete content from users' YouTube accounts.

By using features powered by YouTube API Services, users are also subject to Google's Privacy Policy: https://policies.google.com/privacy

Data Storage and Use

Public creator data retrieved through the YouTube Data API may be stored for internal creator research, caching, deduplication, creator sourcing, and campaign evaluation purposes.

The application is not offered to the general public and does not sell user data or YouTube API data to third parties.

Data Deletion

Stored creator research data may be deleted when it is no longer required for internal business purposes. Authorized internal users may also request deletion of stored application data by contacting the email address below.
